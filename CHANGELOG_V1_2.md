# VEK 1.2.0

VEK 1.2 adds reusable vehicle-editor and game-mode SDK systems for engineering/building games.

- `GameModeSystem` with Survival and Sandbox policies.
- `BuildPartCatalog` with structural, movement, mechanical, functional and experimental categories.
- `VehicleEditorSystem` for snapping, bounds, unlocks, costs, part limits and validation.
- `VehicleBuildCounts` and validation/warning architecture.
- Safe editor natives for `.vek` scripts: mode checks, costs, snapping, placement bounds, power-to-weight, unlocks, basic validation and part limits.
- The existing renderer-neutral advanced GUI system remains available and can now drive host menus/editors.
