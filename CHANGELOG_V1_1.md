# VEK 1.1.0

- Added reusable GravitySystem and gravity script natives.
- Added reusable HealthSystem and health script natives.
- Added procedural RagdollSystem with impact activation, angular collapse, damping and recovery.
- Added renderer-independent advanced GuiSystem command buffer.
- Added script GUI bindings for windows, labels, buttons, checkboxes, sliders, progress bars, text input, separators and spacing.
- Added VEK gameplay helpers (`gravity_step`, `health_damage`, `ragdoll_should_trigger`, etc.).
- Added gameplay-system and GUI command-buffer tests.
- CLI now includes the safe gameplay helper library by default.
